This page cannot name a process by itself. Run the server once and it will do it for you:

curl -fsSL https://th2ch-g.github.io/kanban/serve.sh | sh

Or from source: cargo install --git https://github.com/th2ch-g/kanban.git kanban --locked && kanban serve

the command line it maps to: kanban single -m "HAPPY NEW YEAR" -@ 3 -t 10
